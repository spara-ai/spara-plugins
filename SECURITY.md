# Security policy

Please do not report suspected vulnerabilities in a public GitHub issue.

Email [support@spara.com](mailto:support@spara.com) with the subject
`Security: Spara Claude plugin`. Include the affected component, reproduction
steps, and potential impact. Do not include customer data, credentials, access
tokens, or other secrets in the report.

For Spara's security and compliance practices, see
[Security & Compliance](https://docs.spara.com/developers/spara-api/security-and-compliance).
