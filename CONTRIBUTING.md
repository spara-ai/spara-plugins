# Contributing

Bug reports, installation feedback, and feature requests are welcome in the
[public repository's issues](https://github.com/spara-ai/spara-plugins/issues).
For account-specific help, email [support@spara.com](mailto:support@spara.com)
instead of posting workspace details publicly.

This repository is a release mirror of the plugin maintained with Spara's
application. Please open an issue before preparing a code contribution so the
Spara team can coordinate the matching source change and keep the mirror from
overwriting it.

Never include customer data, credentials, tokens, or private Spara configuration
in an issue or contribution. Report suspected vulnerabilities privately using
[SECURITY.md](SECURITY.md).
